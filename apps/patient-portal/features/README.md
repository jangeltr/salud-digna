# features

Un módulo por dominio, con los mismos nombres que usa la API.

| Carpeta | Dominio | Contrato |
| --- | --- | --- |
| `catalog/` | Estudios y clínicas. | [Estudios](../../../docs/api-studies.md) y [clínicas](../../../docs/api-clinics.md) |
| `requests/` | Solicitud de agendamiento, su contexto y su historial. | [Solicitudes](../../../docs/api-requests.md) y [Journey](../../../docs/api-journey.md) |
| `appointments/` | Citas del paciente. | [Citas](../../../docs/api-appointments.md) |
| `auth/` | Registro, inicio de sesión y cuenta. | [Autenticación](../../../docs/api-auth.md) |
| `identity/` | Vinculación de canales con el paciente. | [Identidad](../../../docs/api-identity.md) |
| `help/` | Ayuda y código de asistencia para Call Center. | [Call Center](../../../docs/api-call-center.md) |
